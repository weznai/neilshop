# 指甲电商独立站 · 完整数据库设计文档（MySQL 8.0）
> 版本 v1.0 · 汇总并整合全部 7 份设计文档中的数据模型，共 **11 域 45 张表**
> 全局约定：utf8mb4 / InnoDB / 金额 DECIMAL(10,2) / 枚举 TINYINT / 时间 DATETIME(3) UTC /
> 主键 BIGINT UNSIGNED AUTO_INCREMENT / 软删用 status / 表名复数避开保留字

## 1. 用户域（5 表）

### 1.1 users — 用户主表

```sql
CREATE TABLE `users` (
  `id`            BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  `email`         VARCHAR(191) NOT NULL,
  `password_hash` VARCHAR(255) NULL,               -- NULL=纯OAuth用户
  `google_id`     VARCHAR(64)  NULL,
  `name`          VARCHAR(100) NOT NULL DEFAULT '',
  `role`          TINYINT NOT NULL DEFAULT 0,      -- 0顾客 1客服 2运营 3仓库 9超管
  `points`        INT NOT NULL DEFAULT 0,          -- 冗余余额(以points_ledger为准)
  `birthday`      DATE NULL,                       -- 生日营销
  `tier`          TINYINT NOT NULL DEFAULT 0,      -- 0普通 1银 2金
  `tier_updated_at` DATETIME(3) NULL,
  `risk_flag`     TINYINT NOT NULL DEFAULT 0,      -- 0正常 1关注 2黑名单
  `total_spent`   DECIMAL(10,2) NOT NULL DEFAULT 0,-- 累计消费冗余
  `last_order_at` DATETIME(3) NULL,                -- 沉睡唤醒判断
  `status`        TINYINT NOT NULL DEFAULT 1,      -- 1正常 0禁用 -1注销
  `email_verified_at` DATETIME(3) NULL,
  `last_login_at` DATETIME(3) NULL,
  `created_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  `updated_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
  UNIQUE KEY `uk_email` (`email`),
  UNIQUE KEY `uk_google` (`google_id`),
  KEY `idx_points` (`points`),
  KEY `idx_tier` (`tier`),
  KEY `idx_last_order` (`last_order_at`)           -- 沉睡用户扫描
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci;
```

```sql
CREATE TABLE `products` (

  `images` JSON NOT NULL,                          -- ["//cdn/1.webp",...]
  `video_url` VARCHAR(500) NULL,                   -- 商品视频(P1)
  `tags` JSON NULL,                                -- ["new","summer","french"]
  `is_new` TINYINT(1) NOT NULL DEFAULT 0,
  `is_best_seller` TINYINT(1) NOT NULL DEFAULT 0,
  `rating_avg` DECIMAL(3,2) NOT NULL DEFAULT 0,    -- 冗余: 异步重算
  `rating_count` INT NOT NULL DEFAULT 0,
  `sold_count` INT NOT NULL DEFAULT 0,             -- 冗余: 异步重算
  `published_at` DATETIME(3) NULL,                 -- 定时上架
  `created_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  `updated_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
  UNIQUE KEY `uk_slug` (`slug`),
  KEY `idx_cat_status_pub` (`category_id`,`status`,`published_at` DESC),
  KEY `idx_best` (`is_best_seller`,`status`),
  KEY `idx_new` (`is_new`,`status`,`published_at` DESC),
  KEY `idx_tag_virtual` ((CAST(`tags` AS CHAR(2000)) ARRAY)),  -- MySQL 8 函数索引(可选)
  CONSTRAINT `fk_prod_cat` FOREIGN KEY (`category_id`) REFERENCES `categories`(`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

### 2.3 variants — 变体表（SKU，甲型×长度）

```sql
CREATE TABLE `variants` (

  `stock` INT NOT NULL DEFAULT 0,                  -- DB权威值
  `safety_stock` INT NOT NULL DEFAULT 5,           -- low stock 展示阈值
  `weight_gram` INT NOT NULL DEFAULT 30,           -- 运费计算
  `version` INT NOT NULL DEFAULT 0,                -- 乐观锁(降级扣库存用)
  `is_active` TINYINT(1) NOT NULL DEFAULT 1,
  `created_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3),
  `updated_at` DATETIME(3) NOT NULL DEFAULT CURRENT_TIMESTAMP(3) ON UPDATE CURRENT_TIMESTAMP(3),
  UNIQUE KEY `uk_sku` (`sku`),
```

## 12. 分库分域与迁移策略（对应微服务演进）

| 阶段 | 数据库形态 |
|---|---|
| 单体(现在) | 1 实例 2 schema：`nailshop_trade`(交易+履约+支付+对账) + `nailshop_biz`(用户/商品/营销/客服/内容/积分/供应链) |
| 拆 trade-svc | `nailshop_trade` schema 直接整体迁走，跨域只走 API/事件 |
| 拆 product-svc | `nailshop_biz` 再分裂出 `nailshop_product`(商品8表+库存流水) |
| 订单膨胀(3年4000万行) | orders 按月分区 → 归档表 `orders_archive`(>1年) → 最后才 ShardingSphere 分片 |

**迁移纪律**：Flyway 管理、只前向、双跑校验、大表变更用 pt-osc/gh-ost。
