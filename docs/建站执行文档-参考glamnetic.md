## 3. 产品页结构（转化关键）

```
① 图片区：手模特写 ×4 + 尺寸对比图 + 佩戴步骤图（首图必须白底/纯色底）
② 信息区：
   - 商品名 + 五星评分（跳评价区）
   - 价格 + 划线原价（compare-at，制造折扣感）
   - 甲型/长度选择器（Short Almond / Medium Square…，选中有示意图）
   - 数量 + 加购按钮（移动端吸底加购栏）
   - 库存紧张提示 + 预计送达时间
   - 信任徽章：正版保证 / 30 天退换 / 安全材质
③ 折叠标签页：如何佩戴（4 步图解）/ 包装清单 / 物流与售后
④ 经常一起买（Bundle 加购组件，如：甲片 + 胶水 -15%）
⑤ 评价区（带图评价置顶）
⑥ 相关推荐：同系列 / 同甲型
```

## 5. Shopify 搭建清单

- [ ] 注册 Shopify（Basic 套餐起步）+ 购买域名

### 5.2 必装 App（控制数量，避免拖慢速度）
| 用途 | App | 备注 |
|---|---|---|
| 评价 | Judge.me | 免费版够用，带图评价 |
| 邮件/弹窗 | Klaviyo | 弃购流程核心 |
| 捆绑/加购 | SCA Elitist 或 Vitals | 全能型，一个顶多个 |
| 倒计时/库存 | 同上 Vitals 内置 | 慎用，过多会廉价感 |
