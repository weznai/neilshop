**渲染策略矩阵（每类页面明确策略，不凭感觉）**

| 页面类型 | 渲染方式 | 理由 |
|---|---|---|
| 首页/列表/详情/博客/FAQ/政策 | **ISR**（详情 revalidate 10min，列表 5min，revalidateTag 精准刷新） | SEO + 商品改价后台保存即刷新标签 |
| 搜索结果/购物车/结算/账户/后台 | **动态 SSR**（no-store） | 个性化数据 |
| 支付成功/订单追踪 | SSR + 客户端轮询 | 状态实时性 |
| 弹窗/加购抽屉/变体选择器 | Client Island | 纯交互 |

### 3.2 核心组件契约示例（TypeScript）

```ts
// ProductCard — 全站复用率最高的组件
interface ProductCardProps {
  slug: string; title: string;
  images: [string, string];            // [主图, hover图]
  priceMin: number; priceMax?: number; // 跨变体价格区间
  compareAtPrice?: number;
  badges?: Array<'new'|'best'|'sale'|'low_stock'|'sold_out'>;
  onQuickAdd?: (slug: string) => void; // 快速加购(默认第一个可售变体)
}

// VariantPicker — 商品详情核心交互
interface VariantPickerProps {
  variants: Array<{
    id: number; option1: string; option2: string;
    price: number; stock: number; image?: string;
  }>;
  selectedId: number | null;
  onSelect: (id: number) => void;
  sizeGuideHref?: string;              // "甲型怎么选?" → 尺码指南弹窗
}

// AddToCartBar — 转化关键组件
interface AddToCartBarProps {
  variantId: number | null; price: number; stock: number;
  expressCheckout?: boolean;           // Shop Pay/ Pay Express 按钮
  onAddToCart: () => Promise<AddCartResult>;
}
// 交互规则: stock=0→"到货通知我"(StockNotify); stock≤safety→"仅剩X件";
// 加购中→skeleton; 成功→CartDrawer自动滑出+recently viewed 记录
```

## 4. 关键页面交互详设

### 4.1 商品详情页（转化主战场）

```
┌─────────────────────────────────────────────┐
│ Gallery(60%)        │ 标题+评分锚点          │
│ ┌─┐┌─┐┌─┐┌─┐缩略图  │ PriceTag(现价/划线/省) │
│ 主图区(可放大)       │ ★尺码指南入口(显眼)    │
│                     │ VariantPicker(甲型图示) │
│                     │ QuantityStepper        │
│                     │ AddToCartBar(吸底)     │
│                     │ [Express Checkout]     │
│                     │ TrustBadges(退换/安全)  │
│                     │ BundleUpsell(+胶水-15%)│
├─────────────────────┴───────────────────────┤
│ ProductTabs: 佩戴4步图解|包装清单|配送退换     │
│ RatingSummary(直方图) + ReviewList(图优置顶)  │
│ 相关推荐(同系列8款横向滑动)                    │
└─────────────────────────────────────────────┘
```
- **变体切换**：Gallery 联动切换 variant_images；价格/库存/角标即时更新（不刷新页面，URL 不变）
- **低库存**：`仅剩 X 件`（橙）→ 售罄变体置灰划线 + "到货通知"按钮（P1）
- **加购反馈**：按钮 → loading → 成功滑出 CartDrawer（含免邮进度条 + 搭配推荐）
- **失效兜底**：ISR 缓存中商品已下架 → fallback 到 404 带推荐位

### 4.2 购物车（抽屉 + 整页双形态）

```
CartDrawer(加购即出): 
  FreeShippingBar "再买$12.03免邮" [██████░░]
  行: 图|名称·变体|价|数量stepper|删除(swap动画)
  折叠: "输入折扣码"(试算即时反馈/差额提示"再买$X可用")
  底: 小计|去结算(粘底) | 你可能还喜欢(横向3卡)
/cart 整页: 同结构 + 清空购物车 + 保存购物车提示
```
- 改数量/删除：**乐观更新**，失败回滚 + toast
- 价格失效：服务端返回现价差异 → 行内提示"价格已更新 $15.99→$13.99"
- 库存失效：行内标红"已售罄"可移除，不阻断其余商品结算

### 4.3 结算页（三栏式）

```
左2/3: ①收货地址(登录用户地址簿选择/新增;游客邮箱+地址, Google补全)
      ②配送方式(Radio: Standard 3-5天 $4.99 / 满$35免 ; Express 1-2天 $12.99)
      ③支付方式Tabs: [💳卡(Apple/GPay自动出)] [PayPal(跳转)] [Klarna 4期] [🎁礼品卡码]
      ④积分抵扣 Slider(可用500分=抵$5, 上限50%)
右1/3: OrderSummary(粘性):
      商品行缩略 · Subtotal / Shipping / Tax / -Code / -Points / Total
      折扣码输入(校验反馈: 未达门槛显示差额)
      [Place Order](loading→跳转对应支付渠道)
      信任: SSL/30天退换/发货时效承诺
```
- **提交后流程**：卡→Stripe Checkout 托管页；PayPal→弹窗授权；成功→`/checkout/success?order_no=`
- **失败兜底**：3DS 失败回到 checkout 保留全部表单与购物车

### 4.4 支付成功页

- 轮询 `GET /api/v1/orders/{orderNo}`（2s×15 次），展示 ✓动画 + 订单摘要 + "保存到账户"(游客注册引导, 注册即合并订单)
- 埋点 `purchase`（以 Webhook 为准，此页只做 UI 确认，防漏报/重报）

### 4.5 后台核心页（以订单详情为例）

```
左: 订单信息卡(状态徽章/金额拆分/UTM来源)
    用户卡(订单数/LTV/退换率/风控标记)
中: 商品明细(变体/数量/已退已换标记)
    收货地址(未发货可编辑)
右: OrderTimeline(内部事件流: 状态/退款/工单/邮件全记录)
    操作区: [退款(金额弹窗,≤$50直退)] [生成RMA] [补发] [备注] [打印面单]
```

## 6. 状态管理与数据流

### 6.1 分层原则（严格边界）

| 数据 | 方案 | 说明 |
|---|---|---|
| 服务端数据(商品/订单/评价) | **RSC 直取 + React Query(仅客户端交互部分)** | 详情页主体 RSC；评价分页用 Query |
| 购物车 | **Zustand(cartStore) + 服务端真源** | 乐观更新→调 BFF→失败回滚; 刷新时从 /api/cart 水合 |
| 会话/用户 | middleware + RSC 注入(layout 取 user 传 Context) | 不入客户端全局 store |
| UI 态(抽屉/弹窗) | Zustand(uiStore) 或局部 state | 弹窗管理器统一调度(互斥规则见§6.2) |
| 表单 | react-hook-form + zod 校验 | 结算/地址/退换向导 |
| URL 态(筛选/排序/分页) | **searchParams 为唯一真源** | 可分享/可回退/SSR 直渲染 |

### 6.2 弹窗互斥调度（体验细节）

```
优先级: ExitIntent > Welcome > Newsletter > BackInStock(主动点击不受限)
规则: ①同一 session 弹过不再弹(Cookie 7天) ②购物车非空时抑制营销弹窗
     ③结账流程中禁止一切营销弹窗 ④移动端 ExitIntent 用"回退意图"触发
实现: <PopupManager/> 客户端组件统一读配置(popup_configs 表)+频控Cookie
```

### 6.3 购物车数据流（详细）

```
加购: cartStore.add(variantId, qty)  // 乐观: UI 立即+1, 抽屉滑出
  → POST /api/v1/cart/items          // BFF 带 session
  ← 成功: 同步服务端购物车快照(数量上限/失效标记)
  ← 失败(20002库存不足): 回滚 + toast"仅剩X件" + 变体置灰
  ← 失败(网络): 重试1次→仍败回滚+toast
登录合并: /login 成功回调 → GET /api/v1/cart/merged → 服务端合并 → 全量水合 store
价格重算: 任何 cart 变更后 → debounce 500ms POST /api/v1/cart/quote
  → 返回 {subtotal, discount, shipping, tax, total, freeShippingGap} 驱动进度条
```

## 7. 性能预算与优化

| 指标 | 预算 | 手段 |
|---|---|---|
| LCP(移动4G) | < 2.5s | Hero priority + AVIF + CDN + RSC 零客户端 JS 首屏 |
| CLS | < 0.1 | 图片固定宽高比(padding-top 占位) / 字体 swap / 广告位预留高 |
| INP | < 200ms | 乐观更新 / 虚拟滚动(评价>50条) / 交互任务切片 |
| 列表页 JS | ≤ 170KB gz | RSC 为主, 筛选栏轻量 client; 禁整页引入大图表库 |
| 图片 | LCP 图预载, 其余 lazy | next/image 统一; CDN 参数(?w=&q=); 双图 hover 用 CSS 切换不加载第三张 |
